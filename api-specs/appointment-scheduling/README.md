# Appointment Scheduling (SSC)

This is the **Appointments** API standard from the Scheduling Standards Consortium (SSC). Convoy, J.B. Hunt and Uber Freight formed the SSC to simplify integration between shippers, carriers and intermediaries and to make appointment scheduling more efficient.

It was moved here from [freightapis/ssc](https://github.com/freightapis/ssc) so that all DSDC standards are in one place. The spec content is unchanged.
